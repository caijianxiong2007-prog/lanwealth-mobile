------------------- 英文(贴给审核员) -------------------

Hello,

Thank you for the feedback regarding Guideline 5.1.1(v).

We have removed the registration requirement. In the new build, the app no
longer requires users to register or log in to use the AI chat:

• On launch, the app opens directly into the chat as a guest. A guest session
  is created automatically with no personal information requested. Guests
  receive free trial credits, so the chat is fully usable without any account.

• To verify: simply launch the app and send a message in the chat — no login
  is required. (If a sign-in screen ever appears, tap "Continue as guest".)

• Registration / sign-in is now entirely OPTIONAL and is only offered for
  account-based features: syncing chat history across devices, using premium
  models, and topping up credits. Free models are available to guests; premium
  models are shown as locked and prompt sign-in.

This change is included in the new build we have submitted for review.

A test account is also available if you would like to review the signed-in
experience:
  Email: apple-review@lanwealth.com
  Password: Bayze-Review-2026

Please let us know if any further information would be helpful. Thank you.

Best regards,
The Bayze AI Team
