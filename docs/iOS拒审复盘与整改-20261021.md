## 根因与上次方案不足

上次演示入口只有会议整理、资料摘要、询价邮件三组本机预置结果，不调用模型，也无法访问真实附件、语音、云同步、用量和账户操作。它可以作为产品示例，但不能替代完整审核访问权限。旧提审记录曾明确保留这个限制；此次应补齐真正的在线审核通道，而不是仅重复解释示例入口位置。

### 登录跳转闪退根因与最终修复

- 临时导航错误边界采到真正 JS 调用栈：getPathDataFromState 的 queryString.stringify，而非 BottomTabBar 自身。此前看到的 BottomTabBar 仅为 React 组件栈入口。
- 现有 query-string 9.5.1 是默认导出，Expo Router 5.1.11 的两处 CommonJS fork 使用 namespace import，访问到 undefined.stringify；无参数冷启动能进入，有参数登录跳转会触发，因而仅靠编译/冷启动无法发现。
